Hipótesis priorizadas: presión de memoria/scheduling amplifica apagado nativo y arranque; acumulación de adquisiciones físicas de las pruebas modernizadas aumenta la carga respecto de R1; retraso del event loop dilata hooks y puede retrasar la entrega de cancelación. No observado: stacks nativos ETW/WPA de Chrome/kernel, parent-PID verificado, CPU exclusiva de un Chromium completo con hijos, page faults por PID, espera SQLite nativa separada, baseline en host con reserva CPU/RAM conocida, distribución p99 de múltiples campañas y overhead aislado.
