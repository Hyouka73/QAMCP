# Revisión arquitectónica independiente de QAP

> **PROPUESTA PENDIENTE DE APROBACIÓN**

## A. Dictamen ejecutivo

**APROBABLE CON CORRECCIONES.** La autoridad única, los adaptadores delgados, los dos carriles persistentes y los oráculos con procedencia son una base viable. El plan actual deja para la integración tardía la verificación de la supervivencia del ejecutor, la recuperación de efectos externos, la publicación portable y la seguridad del corte. Las correcciones preservan los límites de dominio y adelantan una ruta vertical verificable. La autonomía comparable a TestSprite se trata como objetivo de producto, sujeto a pruebas ciegas. El alcance inicial propuesto es QA funcional web/SPA y lecturas API autorizadas, con escrituras de fixtures expresamente autorizadas.

La fuente de diseño es la [entrega de Gemini Neon](gemini-neon-etapa-3.md), basada en `30fb3a2492f9edb4f96b3b0328635ca66401c119`. La referencia de implementación para esta revisión es `origin/develop` en `31836bdc4bf31682b61c5b402d8f4f23e2e67caf`. Ese commit contiene solo documentación sobre `30fb3a2`, con el mismo código. La comparación con `8aeb961a3354580bf87e6f9f67062ff9258857d7` identifica siete commits locales no publicados y sirve para distinguir observaciones de procedencia. El resumen de 82 requisitos de Gemini se conserva como referencia histórica. El comportamiento en navegador y las garantías propuestas quedan sujetos a las compuertas del [plan consolidado](plan-maestro.md#e-compuertas-de-aceptación).

## G. Resolución de la segunda revisión de Gemini Neon

Se contrastaron solo H-REV-01–H-REV-06 con `e766cc33ef5fc635e5f22ebbf46970d34769a097` de `origin/develop`. Su código coincide con `31836bd`. Las decisiones siguientes califican los hallazgos y las correcciones del plan. La propuesta sigue pendiente de aprobación.
