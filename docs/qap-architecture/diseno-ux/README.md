# Expediente consolidado de diseño UX de QAP

**26 de noviembre de 2026 · develop · base documental `d053abc8839e6447ff68a104d025bfa31e7d73a4`**

La propuesta organiza QAP como una mesa de investigación. Una persona abre un expediente, navega entre entidades, prepara una prueba y localiza el testigo que sostiene una conclusión. Cada cambio de representación conserva un ámbito y un vínculo de regreso.

| Entregable | Contenido |
|---|---|
| [Dictamen consolidado](dictamen.md) | Dirección elegida, insumos, decisiones delegadas y alcance. |
| [Especificación funcional y visual](especificacion.md) | Arquitectura de interacción, estados, fronteras y vistas. |
| [Sistema de diseño](sistema-visual.md) | Jerarquía, tokens, componentes, accesibilidad y localización. |
| [Prototipo conceptual autocontenido](prototipo.html) | Una práctica ficticia y un contexto vacío. Abrir el HTML localmente para ejecutar las interacciones de presentación. GitHub muestra el archivo y sus fuentes. |
| [Capturas](capturas.md) | Nueve escenas representativas del HTML final. |
| [Recorridos profesionales](recorridos.md) | Entradas, decisiones, recuperación y salidas. |
| [Trazabilidad normativa](trazabilidad.md) | Obligaciones, controles y asignación a fases. |
| [Revisión, correcciones y reservas](revision.md) | Comparación con la exploración anterior, segunda revisión y alcance de las comprobaciones. |
| [Integración en PM-01 y WBS-01](integracion-pm-wbs.md) | Subtareas propuestas y decisiones materiales reservadas. |

Todo ejemplo, captura y resultado mostrado pertenece a Faro Azul, un caso ficticio. El HTML usa solo datos en memoria y recursos incluidos en el archivo. La publicación documenta la dirección y su revisión, con el estado normativo y las autorizaciones descritos en el [acta de cierre tecnológico](../cierre-av-01/acta-cierre-tecnologico.md). PM-01 y WBS-01 siguen como candidatos.
